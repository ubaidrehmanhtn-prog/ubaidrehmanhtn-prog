## Selected projects

### [AIMS STEM AI Tutor](https://github.com/ubaidrehmanhtn-prog/AIMS-STEM-AI-Tutor)

A small experiment in fine-tuning **Qwen2.5-0.5B-Instruct** with LoRA to explain beginner STEM topics. I trained it in Google Colab, published the adapter on Hugging Face, and documented both the process and its limitations.

[Model adapter](https://huggingface.co/Ubaid328/AIMS-STEM-Tutor-Qwen2.5-0.5B-LoRA) · [Project page](https://huggingface.co/spaces/Ubaid328/aims-stem-ai-tutor)

### [Ghazali Public School Website](https://github.com/ubaidrehmanhtn-prog/Ghazali-Public-School-Website)

A school website and browser-based admin demo built with **HTML, CSS, and JavaScript**. It includes sections for admissions, faculty, results, and school updates. The GitHub repository currently contains the project documentation.

[View website](https://ghazalipublicschoolhathian.netlify.app)

### [Noise Detection with micro:bit](https://github.com/ubaidrehmanhtn-prog/noisedetection)

A small electronics project that reads a noise sensor through a micro:bit and displays the reading on an OLED screen. Built using Microsoft MakeCode.
